# Хостинг

Для хостинга существует определенный набор обязательных точек вызова, чтобы агрегаторы и клиенты могли обращаться к любому хостингу. Они имеют версионирование и будут библиотеки для поддержания старых версий через проксирование вызова. Каждый хостинг отвечает за отдельный вид контента. Во многом это все является адаптацией SEO механизмов

Точки обязательные к реализации:

1) Данные о хостинге. Этот протокол одинаковый для всех типов медиа
4) Получение данных об отдельном контенте. Формат зависит от типа и описан в соседних разделах
5) Получение данных об отдельном авторе
